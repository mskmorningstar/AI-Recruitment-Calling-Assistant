Enable Microphone (macOS)

If microphone access is blocked, follow these steps:

Safari
  1. Safari → Settings → Websites → Microphone
  2. Set localhost to Allow
  3. System Settings → Privacy & Security → Microphone → enable Safari
Chrome
  1. Click the site settings icon next to localhost:3000
  2. Set Microphone to Allow
  3. System Settings → Privacy & Security → Microphone → enable Chrome
No mic required — the Auto Demo and suggested-response buttons work without microphone access.
