# AI Recruitment Calling Assistant
## Overview
The AI Recruitment Calling Assistant is a fully automated system that conducts outbound recruitment
calls using AI voice technology. It integrates with multiple APIs to manage the entire recruitment
calling workflow from candidate sourcing to interview scheduling.
## Functional Scope
### Core Features
- **Automated Outbound Calls**: Uses AI voice to call shortlisted candidates
- **Data Collection**: Gathers current salary, expected salary, notice period, skills confirmation,
location, and work preferences
- **Job Explanation**: Provides detailed job descriptions and company background from ATS data
- **FAQ Handling**: Responds to candidate questions with pre-trained responses
- **Interview Scheduling**: Automatically schedules interviews via Google Calendar or Microsoft
Outlook
- **Real-time Sync**: Syncs all data with ATS/CRM systems in real-time
- **Complete Recording**: Stores transcripts, recordings, and structured answers for recruiter
review

## Technical Architecture
### Technology Stack
- **Backend**: Node.js with Express.js
- **Database**: PostgreSQL with exact schema implementation
- **Telephony**: Twilio for calling and recording
- **Text-to-Speech**: ElevenLabs for dynamic voice generation
- **Speech-to-Text**: AssemblyAI for transcription
- **NLP Processing**: OpenAI/Claude for Q&A parsing from transcripts
- **Calendar Integration**: Google Calendar API / Microsoft Graph

## API Endpoints
### Candidate Management
- `GET /api/candidates` - Fetch all candidates from ATS
- `GET /api/candidates/:id` - Get specific candidate details
- `POST /api/candidates/upload` - Upload candidates via CSV
- `PATCH /api/candidates/:id` - Update candidate information
- `DELETE /api/candidates/:id` - Remove candidate (GDPR compliance)
### Job Management
- `GET /api/jobs` - Fetch all jobs from ATS
- `GET /api/jobs/:id` - Get specific job details
- `POST /api/jobs/sync` - Sync jobs from ATS
### Call Management
- `POST /api/calls/initiate` - Start outbound call to candidate
- `GET /api/calls/:id/status` - Get call status
- `POST /api/calls/webhook` - Twilio webhook for call events
- `GET /api/calls/:id/recording` - Get call recording
- `GET /api/calls/:id/transcript` - Get call transcript
### Interview Scheduling
- `GET /api/interviews/availability` - Check interviewer availability
- `POST /api/interviews/schedule` - Schedule new interview

-- 4 of 9 --

- `PATCH /api/interviews/:id` - Update interview details
- `DELETE /api/interviews/:id` - Cancel interview
### Analytics & Reporting
- `GET /api/analytics/calls` - Call statistics and metrics
- `GET /api/analytics/candidates` - Candidate response analytics
- `GET /api/reports/transcripts` - Transcript analysis reports

## Development Rules
### Core Principles
1. **No Mock Data**: Every function must use real API requests
2. **Direct API Storage**: Store all responses directly from APIs into database
3. **Secure Authentication**: Handle API auth securely via environment variables
4. **Error Handling**: Implement retry logic and comprehensive error handling
5. **GDPR Compliance**: Ensure personal data storage meets privacy regulations
6. **Real-time Processing**: All operations must be real-time with live data
7. **Production Ready**: Code must be ready to run with only .env configuration
### API Integration Requirements
- All database writes must originate from real API responses
- No hardcoded values or placeholder responses
- Implement proper rate limiting and retry mechanisms
- Use production endpoints for all external services
- Maintain audit logs for all API interactions
